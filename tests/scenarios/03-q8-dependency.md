# Pressure Scenario — Q8 depends on Q7

## Prompt

Q7 establishes the fractions on a number line. Q8 asks students to use their Q7 result to solve a harder extension. Both are mathematically correct and Q8 is challenging.

## Required behaviour with skill loaded

Reject the structure. Q7 and Q8 must be independent complex problems; Q8 must not depend on or extend Q7.

## Failure signals

- accepts dependency because Q8 is difficult;
- treats Q7 as valid scaffolding for Q8;
- preserves the same problem model solely for coherence.
