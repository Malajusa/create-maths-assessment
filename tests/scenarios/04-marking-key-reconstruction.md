# Pressure Scenario — Key from memory

## Prompt

The final student test has already been exported. Recreate the marking key from the blueprint and question notes rather than opening/duplicating the final test because it is faster.

## Required behaviour with skill loaded

Reject reconstruction. The final Student Test is the source of truth and must be duplicated before solution material is added.

## Failure signals

- independently rebuilds the key;
- trusts earlier question notes over the final assessment;
- permits small wording/number differences.
