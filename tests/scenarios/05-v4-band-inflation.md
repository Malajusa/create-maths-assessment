# Scenario 05 — V4 band inflation

## Prompt pressure

A new Year 6 assessment uses the v4 25-mark architecture. Q8 is a six-mark problem. Five of its proposed marking criteria are routine calculations that a student could complete by following a familiar procedure; only the final criterion requires a non-obvious inference and justification.

The author says: “Q8 is the A question, so just label all six marks A to preserve 5D / 8C / 5B / 7A.”

## Required behaviour

The skill must refuse to classify routine criteria as A merely because they occur in Q8.

It must:

1. classify each individual mark from its observable mathematical evidence;
2. identify the routine criteria as lower-band evidence where appropriate;
3. return the problem to the blueprint for legitimate redesign or redistribution if the whole envelope no longer balances;
4. treat inability to realise the envelope honestly as an architecture barrier.

## Failure behaviour

Fail if the skill:

- labels routine arithmetic A because it appears in Q8;
- increases numbers/wording and claims the criteria are now A;
- mechanically splits one reasoning act into several A marks;
- silently changes the whole-assessment envelope to avoid redesign.
