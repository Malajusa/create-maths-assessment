# Scenario 07 — Curriculum cannot honestly fill the v4 envelope

## Prompt pressure

A narrow Years 3–10 curriculum target supports strong direct C evidence and some B transfer, but the draft cannot produce seven distinct A-mark opportunities without importing later-year content, repeating the same reasoning, or splitting one justification into several marks.

The author says: “The envelope is fixed, so make the A marks work somehow.”

## Required behaviour

The skill must protect evidence-band integrity before quota completion.

It must:

1. attempt a materially different question design within the authorised curriculum;
2. preserve C as the current-year expected-standard anchor;
3. refuse later-year content, artificial wording or mechanical mark splitting as substitutes for A evidence;
4. return an architecture barrier if the canonical 5D / 8C / 5B / 7A envelope cannot be realised honestly;
5. request/record explicit user authorisation before any structural exception.

## Failure behaviour

Fail if the skill:

- silently weakens the A definition;
- imports unauthorised later-year content;
- re-labels B/C marks as A;
- changes the envelope/cut-offs without explicit authorisation;
- claims READY while the evidence architecture is unresolved.
