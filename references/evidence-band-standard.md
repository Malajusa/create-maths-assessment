# Criterion evidence-band standard

## Purpose

This reference governs evidence architecture for new Years 3–10 mathematics assessments. It supports an indicative standard for the assessed component only; it does not determine the student's reporting grade.

## Canonical envelope

**5D / 8C / 5B / 7A = 25 marks**.

| Score | Indicative standard |
|---|---|
| 0–4 | E |
| 5–9 | D |
| 10–15 | C |
| 16–20 | B |
| 21–25 | A |

The boundaries are derived from the evidence envelope rather than universal percentage bands.

## Structural proof

- C: `10 - 5 = 5` C-or-higher marks are forced.
- B: `16 - 13 = 3` B-or-higher marks are forced.
- A: `21 - 18 = 3` A marks are forced.

No extra post-marking grade rule is required when the assessment passes this structural validation.

## Evidence definitions

**D:** meaningful but limited evidence towards the current year-level construct; simpler, more familiar or partial than satisfactory C evidence.

**C:** satisfactory, independent evidence of the resolved current year-level expectation. C is the anchor for the other bands.

**B:** evidence beyond routine C performance through transfer, independent strategy selection, connection, interpretation, comparison, reverse process or explanation.

**A:** qualitatively stronger reasoning within the authorised curriculum through non-obvious inference, adaptation, interacting constraints, evaluation, sustained reasoning, reconciliation or justification.

Every A mark must name at least one demand feature from: `inference`, `adaptation`, `interacting_constraints`, `evaluation`, `sustained_reasoning`, `justification`.

## Mark-level authority

The individual mark criterion is the authoritative evidence-band unit. Do not infer a band merely from question number, arithmetic size, number of operations, wording length, unfamiliar context, response length, subpart count, or a routine step appearing inside Q7 or Q8.

## Default question pattern

Default marks: `1, 1, 1, 2, 4, 5, 5, 6`.

Default band placement:

- Q1: 1D
- Q2: 1D
- Q3: 1D
- Q4: 2D
- Q5: 4C
- Q6: 4C + 1B
- Q7: 4B + 1A
- Q8: 6A

Per-question placement may vary when the mathematics warrants it, but the whole assessment remains 5D / 8C / 5B / 7A unless the user explicitly authorises a structural exception.

## Scoring model

All earned marks contribute to the total. The assessment is a robust component estimate rather than a complete reporting-grade decision.

If the curriculum scope cannot support the envelope without artificial mark splitting, artificial difficulty or unauthorised content, return an architecture barrier rather than relabelling weak evidence.

Exact supplied assessments, key-only requests and equivalent Version B requests preserve their source architecture unless migration is explicitly requested. Pre-primary–Year 2 and Years 11–12/WACE remain outside this default envelope unless separately specified.
