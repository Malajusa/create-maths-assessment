## Search patterns

Use `rg` within the selected file when locating a strand, code or phrase:

```bash
rg -n 'Achievement standard|Content descriptions|Number and algebra|Measurement and geometry|Statistics and probability' references/curriculum-year-5.md
rg -n 'WA5M|fraction|area|time|probability' references/curriculum-year-5.md
```

Read the surrounding content, not only the matching line. Examples in the curriculum clarify scope but are not exhaustive mandatory assessment items.

## Interpretation rules

- Use the exact content code and description.
- Read the whole Achievement Standard before selecting evidence.
- For mixed-year tasks, compare both year files and explicitly establish valid overlap before designing one common assessment.
- Treat overlap as valid only when the higher-year topic continues, applies or depends on the previous year's concept and one coherent task can produce identifiable evidence for both levels.
- If valid overlap is absent, create or recommend separate aligned assessments rather than forcing both levels into one task.
- Treat optional Year 9 and Year 10 content as optional.
- Do not represent curriculum examples as mandatory teaching or assessment requirements.
- Do not import higher-year content merely to manufacture an A-level question.
- State when an assessment covers only part of a content description or Achievement Standard.
