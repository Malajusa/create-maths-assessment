# Assessment Contract

## Default output

A complete run produces:
- Student Test PPTX;
- Marking Key PPTX;
- Curriculum Rationale PDF.

## Default Years 3–10 structure

For a new grade-estimating assessment using `criterion_component_estimate_v1`, use the standard eight-question **25-mark** structure:

| Question | Marks | Default evidence role |
|---|---:|---|
| Q1 | 1 | 1D |
| Q2 | 1 | 1D |
| Q3 | 1 | 1D |
| Q4 | 2 | 2D |
| Q5 | 4 | 4C |
| Q6 | 5 | 4C + 1B |
| Q7 | 5 | 4B + 1A |
| Q8 | 6 | 6A |

Mark sequence: **1, 1, 1, 2, 4, 5, 5, 6**.

Whole-assessment evidence envelope: **5D / 8C / 5B / 7A**.

Indicative standard on the assessed component:

- E: 0–4
- D: 5–9
- C: 10–15
- B: 16–20
- A: 21–25

The evidence envelope, not conventional percentages, makes these cut-offs meaningful. C/B/A boundaries structurally force at least 5/3/3 target-or-higher marks respectively.

This is a default for new Years 3–10 grade-estimating assessments. It does not override an explicit user-specified structure, a supplied assessment that must be preserved exactly, Pre-primary–Year 2 age-appropriate structures, or Years 11–12/WACE course requirements.

## Evidence-band contract

Use `references/evidence-band-standard.md`.

The individual mark criterion is the authoritative evidence-band unit. Each mark must state observable evidence, D/C/B/A band, a band rationale and why the next lower band is insufficient. A marks also require a named A-demand feature.

C is the expected-standard anchor. D represents meaningful but limited evidence towards the same construct. B requires transfer or stronger independent application beyond routine C performance. A requires non-obvious, flexible or justified reasoning within the authorised curriculum.

Do not create band demand through larger numbers, more operations, longer prose, unfamiliar formatting or question position.

## Question design

- Questions must be meaningfully varied.
- Difficulty must reflect mathematical demand, not irrelevant barriers.
- Q7 and Q8 are independent.
- Complex problems require students to determine relevant mathematics rather than merely follow supplied steps.
- Context should support the mathematics rather than decorate it.
- Student-facing content must avoid unnecessary instructions and non-essential visual elements.
- If the curriculum cannot support the required 5D / 8C / 5B / 7A envelope honestly, return an architecture barrier instead of inflating evidence bands.

## Marking key

The marking key is a duplicate of the final assessment with worked solutions and mark allocation added. It must never be rebuilt from memory or from an earlier draft.

For v4 assessments it may display teacher-facing evidence bands and the indicative component score table. It must distinguish that indication from a student's official reporting grade.

## Rationale

The rationale describes what the final assessment actually assesses. It must not claim curriculum coverage that is absent from the final questions.

For v4 it also records the evidence envelope, band definitions as applied to the assessed mathematics, structural boundary proof and the limitation that the A–E indication applies only to the assessed component.
